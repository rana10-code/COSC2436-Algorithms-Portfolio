# COSC 2436 - Algorithms Portfolio

A semester-long collection of 12 chapter labs covering data structures and
algorithms in Python. Each chapter folder contains the working program files
plus a written lab report.

---

## Author

Dhiraj Rana - COSC 2436, Spring 2026

---

## Description

This portfolio contains programming labs completed throughout the semester for
COSC 2436: Programming Fundamentals III (Data Structures and Algorithms).
The projects explore important computer science concepts including searching
algorithms, sorting methods, recursion, graph traversal, trees, dynamic
programming, shortest-path algorithms, and introductory machine learning
techniques.

The goal of this portfolio is to demonstrate understanding of algorithm
design, time complexity analysis, data structures, and problem-solving
techniques using Python.

---

## How to Run a Lab

Each lab is a standalone Python program.

Example:

```bash
cd CH01
python3 main.py
```

---

## Requirements

- Python 3.10 or newer
- Some labs may require additional packages
- Install required packages using:

```bash
pip install -r requirements.txt
```

from inside the appropriate chapter folder.
